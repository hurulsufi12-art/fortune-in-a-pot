# Fortune in a Pot

One line (115 characters, limit 120): a kind, funny fortune for a houseplant on the windowsill — a new leaf, the morning sun, a keeper who brags.

> Soon a brave new leaf unfurls, the sun finds your windowsill first, and your keeper brags about you to every guest.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
